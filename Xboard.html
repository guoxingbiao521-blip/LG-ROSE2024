🛠️ 第一步：安装核心压测工具
先装上用来模拟真实负载的 stress-ng：

Bash
apt-get update && apt-get install -y stress-ng

📝 第二步：写入波浪形防回收脚本
直接复制下面这整段代码粘贴回车。逻辑跟之前一模一样，完美带入随机休息与动态波动：

Bash
cat << 'EOF' > /root/oracle_alive.sh
#!/bin/bash

# 无限循环模拟真实业务请求
while true; do
    # 随机生成 25 到 45 之间的 CPU 负载百分比
    CPU_LOAD=$((25 + RANDOM % 21))
    
    # 随机生成 25 到 40 之间的内存占用百分比
    MEM_LOAD=$((25 + RANDOM % 16))
    
    # 随机生成这次负载的持续时间：600秒 到 1800秒（10 到 30分钟）
    RUN_TIME=$((600 + RANDOM % 1201))
    
    # 随机生成一小段闲置休息时间：60秒 到 300秒（1 到 5分钟），让波形有下降的间隙
    SLEEP_TIME=$((60 + RANDOM % 241))

    # 执行模拟负载
    stress-ng --cpu 1 --cpu-load $CPU_LOAD --vm 1 --vm-bytes ${MEM_LOAD}% --timeout ${RUN_TIME}s --quiet

    # 负载结束后休眠一会儿
    sleep $SLEEP_TIME
done
EOF

# 给脚本执行权限
chmod +x /root/oracle_alive.sh

🛡️ 第三步：配置后台守护运行（开机自启）
继续把下面这整段复制回车，把它注册成系统底层服务，保证它以后就算遇到服务器重启也能自己爬起来接着干活：

Bash
cat << 'EOF' > /etc/systemd/system/oracle_alive.service
[Unit]
Description=Oracle Keep Alive Dynamic Load
After=network.target

[Service]
Type=simple
User=root
ExecStart=/root/oracle_alive.sh
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

🚀 第四步：一键启动并生效！
最后，敲下面这三行命令，让这台巴西服务器的防回收服务立马开工：

Bash
# 1. 重新加载服务列表
systemctl daemon-reload

# 2. 设置开机自启动
systemctl enable oracle_alive

# 3. 立即启动服务
systemctl start oracle_alive

🔍 搞定！查岗确认：
四步跑完之后，老规矩敲一行状态查询命令：

Bash
systemctl status oracle_alive

🛠️ 第一阶段：系统环境与防火墙

1. 更新系统并安装所有必备工具 (跑完会回到输入提示符)

Bash
apt update && apt install -y curl socat wget net-tools iptables-persistent

2. 永久放行专属 TCP 端口

Bash
iptables -I INPUT -p tcp -m multiport --dports 80,443,8443,42719,23361,52438 -j ACCEPT

3. 永久放行专属 UDP 端口

Bash
iptables -I INPUT -p udp -m multiport --dports 80,443,8443,42719,23361,52438 -j ACCEPT

4. 保存防火墙规则，确保重启不丢失

Bash
netfilter-persistent save && netfilter-persistent reload

5. 下载并安装 Docker 核心引擎

Bash
curl -fsSL https://get.docker.com | bash

6. 设置 Docker 开机自启

Bash
systemctl enable --now docker

🔐 第二阶段：申请与提取 SSL 证书

7. 安装 acme.sh 证书工具

Bash
curl https://get.acme.sh | sh

8. 刷新环境变量，让工具生效

Bash
source ~/.bashrc

9. 强制将发证机构切换为 Let's Encrypt

Bash
~/.acme.sh/acme.sh --set-default-ca --server letsencrypt

10. 强制申请证书

Bash
~/.acme.sh/acme.sh --issue -d .zmdz.cloud --standalone --force

11. 创建证书存放目录

Bash
mkdir -p /root/cert

12. 提取并安装证书

Bash
~/.acme.sh/acme.sh --installcert -d .zmdz.cloud --ecc --key-file /root/cert/.zmdz.cloud.key --fullchain-file /root/cert/.zmdz.cloud.crt

13. 打印公钥证书

Bash
cat /root/cert/.zmdz.cloud.crt

14. 打印私钥文件

Bash
cat /root/cert/.zmdz.cloud.key

🚀 原生一键开启 BBR 提速

写入配置并应用：

Bash
sed -i '/net.core.default_qdisc/d' /etc/sysctl.conf
sed -i '/net.ipv4.tcp_congestion_control/d' /etc/sysctl.conf
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p

Bash
